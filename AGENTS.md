# Временное открытие витрины — 13 октября 2026

По просьбе пользователя Basic Auth на `againdev3.ru` временно отключена
для просмотра и проверки витрины. Это временный режим, не постоянное решение.

**Последний обязательный шаг после завершения всех проверок витрины:**

1. В `server/middleware/basic-auth.ts` вернуть `DEV_BASIC_AUTH_ENABLED = true`.
2. Закоммитить и запушить изменение; пересобрать витрину на сервере и
   перезапустить `nuxt-shop` по `../lara_admin/docs/deploy-runbook.md`.
3. Проверить, что запрос без авторизации возвращает HTTP 401 и
   `WWW-Authenticate: Basic`, а запрос с действующим входом — HTTP 200.
4. Обновить отметку в этом файле и runbook: защита восстановлена.

Не возвращать защиту сразу после текущего временного открытия: пользователь
должен успеть выполнить просмотр и дальнейшие проверки. Возврат защиты
уже согласован пользователем как завершающий шаг этих работ.
